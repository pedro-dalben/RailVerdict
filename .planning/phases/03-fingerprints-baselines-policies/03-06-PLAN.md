1. **Initial state 3 offenses** → `railverdict baseline create` (CLI path) writes `.railverdict-baseline.json` atomically (assert file exists, valid against baseline schema, 3 entries, sorted fingerprints, no source/creds/logs/prompts keys).
2. **Changed scenario: 2 remain, 1 resolved, 1 introduced** → `railverdict check` with that baseline classifies `existing:2 resolved:1 introduced:1` (assert `comparison.counts` and `findings` states in JSON via `Reporters::JsonReporter` and `JSON.parse`).

   - `strict` → FAIL according to complete current findings.
3. **Waiver scenario**: create exact active waiver for the introduced fingerprint in `.railverdict-waivers.json` (UTC `created_at` now, `expires_at` +1h) → `railverdict check` shows finding as `waived` visible and non-blocking per policy (no_new_debt PASS when only that introduced was waived). - complete run creates baseline
- incomplete run (stub rubocop unavailable via rubocop_command_resolver returning missing executable) refuses baseline creation, no file
- existing baseline not silently overwritten without --force; with --force overwrites
- interrupted write leaves old baseline intact (stub `File.rename` raise inside `Baseline.write`; assert original content/hash unchanged, no tmp file)
- malformed baseline (hand-edited JSON with trailing comma) fails closed with `baseline_incompatible`
- unsupported fingerprint_version (e.g., 99) fails closed with explicit migration message
- current check does not mutate baseline file (mtime/hash unchanged after `Check.execute`/`run_cli check`)
- current check does not mutate waiver file
- baseline contains no source code/full logs/prompts (scan JSON keys for forbidden substrings)
- deterministic output across locale/tz/tmpdir (extend determinism test to include baseline)
- large but reasonable baseline (e.g., 2000 fingerprints via synthetic findings) classifies in bounded time with Hash lookup

Keep tests focused, English-only, no network, injected clocks (`Time.utc`).
