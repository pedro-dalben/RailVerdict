  <action>
Create `schemas/baseline-v1.schema.json` Draft 2020-12:

- `$id: https://railverdict.dev/schemas/baseline/v1.schema.json`, `additionalProperties: false`, `unevaluatedProperties: false`.
- Required: `schema_version (const "1.0")`, `fingerprint_version (integer const 1)`, `algorithm (const "sha256")`, `payload_schema (const "https://railverdict.dev/fingerprint-payload/v1")`, `created_at (string date-time UTC Z)`, `created_by (string 1..256, e.g., "railverdict 0.1.0")`, `configuration_digest (string ^[0-9a-f]{64}$)`, `analyzer_versions (object with string values 1..128)`, `entries (array of {fingerprint: ^sha256:[0-9a-f]{64}$, analyzer: 1..256, rule_id: 1..256, path: repository-relative pattern, first_seen: date-time Z})` sorted by fingerprint (runtime check).
- No `source_code`, `credentials`, `full_logs`, `ai_prompts`, `diffs`, `env` fields — reject unknown.

Implement `lib/rail_verdict/baseline.rb`:

- `Baseline::IncompatibleError < RailVerdict::Error` with `code: "baseline_incompatible"` semantics.
- `Baseline.create(findings:, configuration:, analyzer_versions:, clock: Time.now.utc)` → builds canonical Hash in memory (entries sorted by fingerprint, deduped by fingerprint), sets `created_at = clock.utc.iso8601`, `created_by = "railverdict #{VERSION}"`, validates via `SchemaValidator.validate_baseline`, returns `Baseline` value object (frozen). No I/O.
- `Baseline.read(path)` → `File.binread`, `JSON.parse`, validate with schema + runtime checks: duplicate fingerprints, `fingerprint_version != 1` or `algorithm != sha256` → raise `IncompatibleError` with message requiring explicit migration (`baseline vX requires explicit migration: re-create with railverdict baseline create`), corrupted JSON → `IncompatibleError`, unknown schema_version → `IncompatibleError`. Never reinterpret permissively.
- `Baseline.validate_hash(hash)` helper for CLI and tests.

Extend `lib/rail_verdict/schema_validator.rb` with `BASELINE_SCHEMA = "baseline-v1.schema.json"` and `validate_baseline(data)` plus `load_schema` support.

Update `lib/rail_verdict/errors.rb` if needed for new error class.

Require baseline from `lib/rail_verdict.rb`.

Keep `check` read-only — do not wire baseline loading in this plan; only CLI `baseline create` will call `Baseline.create` next task.
  </action>
  <acceptance_criteria>
    - Baseline format is versioned and stores only compact fingerprints + minimal reproducibility metadata; schema rejects source/creds/logs/prompts/diffs/env.
    - Reader fails closed on unknown schema/fingerprint version, invalid structure, duplicate entries, corrupted file, unsupported future format with explicit migration error.
    - In-memory `create` validates before any I/O.

Add `schemas/configuration-v1.2.schema.json` additive to v1.1: same as v1.1 plus optional top-level `baseline: {type: object, required: [], properties: {path: {type: string, minLength: 1, maxLength: 1024}}, additionalProperties: false}`. Version const 1.2. Keep 1.1 support: `Configuration.load` must accept both 1.1 and 1.2 (extend SUPPORTED_VERSIONS). Update `SchemaValidator.validate_configuration` to branch on version 1.2. Add `examples/configuration-v1.2.yml` illustrating `baseline: {path: .railverdict-baseline.json}`.

Implement atomic write in `lib/rail_verdict/baseline.rb`:

- `Baseline.default_path(repository_root)` → `File.join(root, ".railverdict-baseline.json")`.
- `Baseline.resolve_path(repository_root:, configuration:, output_override:)` → precedence: `output_override` absolute or expanded against root, else `configuration.baseline_path` if config has `baseline.path`, else default.
- `Baseline.write(path:, baseline:, force: false)` → raise `UsageError` if file exists without `force`; otherwise write atomically: `Dir.mktmpdir` or `Tempfile.create` in same directory, `File.open(tmp, "wb", 0600)`, `write(JSON.pretty_generate(canonical_hash) + "\n")`, `fsync`, `File.rename(tmp, path)`, `fsync` dir if possible, `ensure File.unlink(tmp) if File.exist?(tmp)`. Never partially replace on failure.
- `Baseline.write_atomic` is the only writer; `Check.execute` must not call it.

Extend `lib/rail_verdict/cli.rb#command_baseline`:

- Parse already handles `--config`, `--output`, `--format`. Add `--force` (consistent with `init --force`). Resolve root, load configuration, call `Check.execute` to obtain a complete trustworthy run (all required analyzers succeeded). If result `completion_status != complete` → print to stderr `baseline create refused: required evidence is incomplete` and exit 2 without writing. Otherwise build baseline via `Baseline.create(findings: outcome.findings, configuration: outcome.configuration, analyzer_versions: outcome.context.analyzer_versions, clock: Time.now.utc)` and `Baseline.write(path: resolved, baseline: baseline, force: options[:force])`. Render console `Baseline created at <path> (N entries)` or JSON `{baseline: baseline.to_h}` per format. Validate before write; on failure remove tmp and exit 2. If baseline already exists without `--force` → stderr `baseline already exists; use --force to overwrite` exit 2.

Update `lib/rail_verdict/check.rb` only to expose `Check.registry` / `outcome.context.analyzer_versions` if needed — but do not make `check` write baseline. Add a comment guard that `check` is read-only.

Keep stubs English-only; use `with_tmpdir` + `FileUtils.cp_r` for fixture isolation like Phase 01/02.
