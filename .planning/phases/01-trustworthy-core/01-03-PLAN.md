  <action>
Implement `RailVerdict::ProcessRunner.run(executable, argv, chdir:, timeout_seconds:, max_stdout_bytes:,
max_stderr_bytes:, env_overrides:)`:
verify `chdir` exists and is a directory (raise `RailVerdict::ProcessRunner::DirectoryError` otherwise);
spawn with `Process.spawn(env, [executable, File.basename(executable)], *argv, chdir:, pgroup: true, in: :close,
out: pipe, err: pipe)` — never a shell string and argv elements are passed verbatim (no shell metacharacter
interpretation possible); env is computed from an explicit allowlist of the parent ENV
(`PATH HOME GEM_HOME GEM_PATH RUBYLIB RUBYOPT LANG BUNDLE_GEMFILE BUNDLE_PATH BUNDLE_WITH BUNDLE_WITHOUT`) plus forced
`LC_ALL=C.UTF-8` and `TZ=UTC`; drain stdout and stderr concurrently with `IO.select`, independent byte caps
(defaults 4 MiB stdout, 64 KiB stderr) marking the affected stream truncated and closing it on overflow; enforce a
monotonic deadline with `Process.clock_gettime(Process::CLOCK_MONOTONIC)`; on timeout send `TERM` to `-pgid`, brief
grace, then `KILL`, reap with `Process.waitpid`, and report `:timed_out`; report `:signaled` with the terminating
signal when the child dies by signal; report `:spawn_failed` with the errno for ENOENT/EACCES; always close pipes and
reap in `ensure`. Return frozen `RunResult` facts: `status` (`:exited`, `:timed_out`, `:signaled`, `:spawn_failed`),
`exit_code`, `signal`, `stdout`, `stderr` (binary strings, valid UTF-8 forced with replacement), `stdout_truncated`,
`stderr_truncated`. Provide a pid registry (`register/unregister/kill_all`) guarded by a Mutex so the CLI interrupt
trap can terminate process groups and wait before exiting 130; the registry clears entries after reap. Create
`test/fixtures/stubs/` synthetic child programs: `echo_argv_json` (prints ARGV as JSON), `env_report` (prints selected
ENV keys as JSON), `sleep_forever`, `spam_stdout` (bounded loop printing until killed), `exit_with` (exits with argv
code after optional stderr/stdout payloads), `self_signal` (raises an unhandled fatal signal), `grandchild_sleep`
(spawns a detached grandchild then sleeps) — all English-only, deterministic, no network.
  </action>
  <acceptance_criteria>
    - A repository-controlled argv element containing spaces, quotes, `$(...)`, backticks, `;`, newlines, and a leading
      dash is delivered to the child byte-for-byte as a single argv entry (proven by `echo_argv_json`).
    - Child environment contains only allowlisted parent keys plus forced `LC_ALL`/`TZ`; parent-only variables are
      absent (proven by `env_report`).
    - No `system`, backtick, or single-string spawn form exists in the runner source.
  </acceptance_criteria>
