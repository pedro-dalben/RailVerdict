# 1.8 Agent Workflow — Implementation Report

## Architecture decision
Compositional release over frozen 1.7 contracts (ADR 0021): no gate, policy,
receipt, handoff, or PR-intelligence meaning changed. Three new documents
(`review-packet-v1`, `review-observation-v1`, `workflow-receipt-v1`) plus an
additive repair-plan extension, all served by canonical services shared between
CLI (`review show|observe|complete`, `repair verify`) and MCP
(`get_review_packet`, `verify_review_observation`, `create_workflow_receipt`;
13 → 16 tools). Folded, not duplicated: ProjectPolicy → packet `policy`
section, VerificationPlan projection → packet `plan` section,
EvidenceRecoveryContext → packet `recovery` section.

## Honesty mechanics
- Observation validation order: shape → author/provider trust → schema detail
  → integrity → binding. `untrusted` is reachable (unknown author, missing
  provider), not shadowed by schema.
- Trust checks precede schema detail by design; integrity recomputes
  `observation_id` over canonical JSON.
- Workflow assembly refuses packet/decision mix-and-match; readiness moves
  only on fresh verification, never on observations.
- MCP inline documents are key-normalized through a JSON round-trip (SDKs may
- Repair-plan extension reports observed execution (what ran, test scope,
  requirement statuses), never predictions; the internal engine stays the only
  predictor, re-run via the unchanged `required` argv.

## Validation
- Full suite: **710 runs, 2982 assertions, 0 failures, 0 errors**
  (5 environment-conditional minitest skips under Bundler; real proof outside
  Bundler green).
- New tests: 37 (14 workflow unit, 10 adversarial, 5 schema contract, 3 BYOA
  consumers, 5 CLI exit-ladder).
- External Lab full catalog `--all` against the build-once 1.8.0 artifact:
  **172/172 PASS** (161 pre-existing + 11 `RVLAB-WF-*`), 0 FAIL/BLOCKED/SKIPPED.
- CLI/MCP parity proven (identical packet ids); determinism proven
  (byte-identical repeats); stale/tampered/untrusted observations proven
  black-box; repair loop proven end-to-end (fix → successful).
- Agent experiment (exploratory, single operator, pre-registered, n=20):
  packet arm 0/10 false successes vs control 6/10, correct routing 10/10 vs
  4/10, median turns 2 vs 3. Fabrication boundary observed (treatment left
  coverage.json untouched). Non-generalizable by design; see
  `docs/release/1.8-agent-experiment.md`.

## Adversarial notes
Prompt injection stays data; PASS-claims over FAIL gates change nothing;
replay never upgrades readiness; lane confusion rejected by schema; oversized
and malformed inputs are `invalid`; AI observations enter only as
`author: ai` with confidence and provider, `authoritative: false` required.

## Limitations
- Review-approval presence still has no verifiable proof; `REVIEW_REQUIRED`
  clears only when the trigger goes away (deferred since ADR 0020).
- No observation store: observations live with their authors; only copies
  validate (multi-signer thresholds deferred).
- The lab tree carries a pre-existing rubocop offense
  (`app/services/legacy_audit_logger.rb`, fixture content since baseline);
  absorbed by baselines where configured; WF scenarios pin WARN where advisory
  surfaces it.
- IntegrarPlus full-suite dogfooding not repeated (shared-database risk, G0 rule).
