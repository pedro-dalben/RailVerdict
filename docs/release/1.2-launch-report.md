## Known limitations (explicit, non-blocking)

- Ruby 4.0 CI lane not yet run (STACK recommendation).
- Branch protection NONE on master/lab main — recommend enabling.
- RVLAB-16 waiver injection: adding waiver after FAIL reports `gate: PASS` with `verification_boundary_changed:{waivers:true}` — mitigated by receipt stale; hard gate rejection is POST-1.2.
- Snapshot guard not linearizable (mutate-and-revert inside verification window can be missed — ADR 0016).
- Analyzer version drift only flagged as `analyzer_environment_changed` when caller supplies fresh versions.
- No Brakeman, no OS sandbox, no full semantic code graph, no signing — per charter.
- `FOUNDATION_PRIVATE_PATTERNS` provenance scan NOT RUN until maintainer-supplied — NON-BLOCKING by decision 2026-08-19.
