## 1. Executive Summary

RailVerdict 1.4 (Agent Handoff & Evidence Reuse) introduces cryptographic Receipts, immutable Repository State Identity, and cross-agent Handoff packets. However, real-world consumer dogfooding against a complex Rails application (`IntegrarPlus`) and an independent trust audit revealed that the underlying evidence-acquisition layer inherited several critical defects that compromised evidence fidelity.

Specifically, 4 **P0 Trust Failures** were identified:
1. **RSpec Process/Report Reconciliation (RH-02):** Process exit code was ignored if JSON summary had `failure_count == 0`, converting infrastructure failures and syntax errors into False PASS.
2. **Minitest Process/Report Reconciliation (RH-03):** Process exit code was ignored if reporter summary had `failures == 0`, converting `at_exit` crashes and abnormal terminations into False PASS.
3. **SimpleCov Path Containment (RH-07):** Absolute external paths (e.g. `/etc/passwd` or outside repos) had leading slashes stripped, causing repository boundary breaches and false coverage attribution.
4. **VerificationEnvironment Execution Identity (RH-09):** Global binary fallback on PATH when `bundle exec` failed synthesized false environment identities, enabling False Freshness and False Evidence Reuse.

All 10 hardening findings (**RH-01 through RH-10**) have been completely remediated, characterized, verified against the internal suite (581 runs, 0 failures), certified via the external black-box Validation Lab (118/118 scenarios PASS), and dogfooded live against `IntegrarPlus`.

## 3. Remediation Audit Matrix (RH-01 through RH-10)

| ID | Category | Severity | Description | Remediation Applied | Invariant Enforced |
|---|---|---|---|---|---|
| **RH-01** | Evidence Transport | **P1** | RSpec structured JSON parsed from stdout; application/audit stdout pollution caused `parse_failed` $\rightarrow$ INCOMPLETE. | Passed `--format json --out <TEMP_FILE>` via controlled `Dir.tmpdir` tempfile; stdout is diagnostic only. | RSpec evidence isolation from arbitrary stdout. |
| **RH-02** | Evidence Integrity | **P0** | RSpec exit code ignored if JSON parsed; abnormal exit with 0 failed examples produced False PASS. | Reconciled process exit code: exit 0 requires 0 failures; exit 1 requires $>0$ failures; exit 1 with 0 failures or exit $>1$ returns `failed` (INCOMPLETE). | Contradictory or abnormal process exits fail-closed. |
| **RH-03** | Evidence Integrity | **P0** | Minitest exit code ignored; stdout fallback enabled if output file absent, causing False PASS on process crash. | Moved reporter output to `Dir.tmpdir`; removed stdout JSON fallback; reconciled exit code (exit 1 with 0 failures returns `failed`). | Minitest process crash or missing reporter fails-closed. |
| **RH-04** | Execution Identity | **P1** | `resolve_reporter_path` queried `Gem::Specification.find_all_by_name.max_by(&:version)`, loading foreign installed gems. | Binds reporter strictly to `__dir__` relative path or `Gem.loaded_specs["rail_verdict"]`. | Distribution self-containment; zero cross-version pollution. |
| **RH-05** | Contract Compliance | **P1** | Native SimpleCov parser accepted version 0.20+, violating declared `>= 1, < 2` contract. | Enforced `SUPPORTED_VERSION_RANGE = Gem::Requirement.new(">= 1", "< 2")` on all formats; removed `"1.0"` synthesis. | SimpleCov declared contract strictly enforced. |
| **RH-06** | Determinism | **P1** | Missing timestamp in native SimpleCov JSON fell back to `Time.now.to_i`, causing nondeterministic digests. | Replaced `Time.now` fallback with deterministic sentinel integer `0`. | SimpleCov document normalization is 100% deterministic. |
| **RH-07** | Path Confinement | **P0** | `normalize_native_path` stripped leading `/` on external files, converting `/etc/passwd` to `etc/passwd`. | Raised `MalformedOutput` if resolved file escapes `repository_root` (via `Pathname#relative_path_from`). | Strict repository path confinement; zero external aliasing. |
| **RH-08** | Configuration Confinement | **P1** | Configured `coverage_path` allowed absolute or relative paths escaping repository root (`../../coverage.json`). | Added `resolve_contained_coverage_path` rejecting paths outside `repository_root` as `malformed`. | Configuration path confinement fail-closed. |
| **RH-09** | Execution Identity | **P0** | `VerificationEnvironment` fell back to global executables on PATH when `bundle exec` probe failed. | Removed `probe_fallback` completely. Failed probe on required/enabled analyzer marks `available: false`. | Authoritative execution identity; zero false freshness/reuse. |
| **RH-10** | Operational Reliability | **P1** | `resolve_probe_timeout` passed suite timeout (e.g. 600s) into `--version` probe. | Clamped probe timeout to `<= 5.0` seconds across `VerificationEnvironment`, `Check`, `Doctor`, and all analyzer probes. | Fast fail-closed probes; suite timeouts never leak into probes. |
