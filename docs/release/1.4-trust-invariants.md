# RailVerdict 1.4 — Trust Invariants (Frozen — Stage 1)

**Status: Frozen 2026-08-25 — Stage 0 investigation complete, Stage 1 invariants locked**
**Source: `docs/release/1.4-stage-0-investigation.md` §§1-15**

No implementation may weaken these. Any P0 trust defect fails audit.

1. **A Handoff never authorizes its own reuse.** Only receiver decides `REUSABLE` vs `VERIFICATION_REQUIRED` after independent observation.

2. **Current state is independently observed.** Receiver re-observes `RepositoryState` + `VerificationEnvironment` via `VerificationIdentity`; sender values are not trusted as current.

3. **Receipt freshness is necessary but not sufficient for reuse.** `RECEIPT_FRESH` ⇒ candidate for `EVIDENCE_REUSABLE`, never sufficient alone (see bundler-audit DB, policy change, scope mismatch).

4. **Reuse cannot bypass required evidence.** Missing required analyzer evidence ⇒ `VERIFICATION_REQUIRED`, never empty success.

5. **Missing reusable evidence cannot become empty successful evidence.** Incomplete evidence (`unavailable`, `unsupported`, `timed_out`, etc.) never reused as complete.

6. **Old GateResult cannot silently become current policy authority.** Only current `GateResult` produced by canonical pipeline (`reused evidence + new evidence → baseline → waivers → policy`) is authoritative.

7. **Policy changes must be evaluated by the current canonical policy engine.** Evidence may be reusable while policy drift forces new `GateResult`.

8. **Reuse cannot bypass baseline evaluation.** Current `baseline_digest`/comparison re-applied.

9. **Reuse cannot bypass waiver evaluation.** Current `waivers_digest` + expiry (UTC) re-applied.

10. **Reuse cannot bypass Git scope.** `changed` vs `full`, `base`/`merge_base`/`HEAD`/`index`/`worktree` mismatches ⇒ `VERIFICATION_REQUIRED`.

11. **Reuse cannot bypass analyzer requirement changes.** `enabled+required` added ⇒ prior evidence incomplete; `disabled` ⇒ old evidence ignored.

12. **Unobservable reuse predicates fail closed.** `analyzer_version_unobservable`, `provenance_unobservable`, `advisory_database_unobservable` ⇒ `VERIFICATION_REQUIRED`/`UNAVAILABLE`, never `REUSABLE`.

13. **Reuse decision is deterministic.** Same inputs (handoff payload, current digests, current contract) → same decision; reason ordering deterministic.

14. **Handoff identity is deterministic.** `handoff_id = sha256(canonical_json[trusted_payload])`, insensitive to JSON key order, insensitive to timestamps/PID/host/path/duration, sensitive to trust-relevant content.

15. **Absolute checkout path does not affect portable identity** unless explicitly justified; `RECEIPT_FRESH`/`EVIDENCE_REUSABLE` must be clone-portable for equivalent `RepositoryState`/`VerificationEnvironment`.

16. **Handoff tampering is detectable through deterministic content identity.** Any byte change → `handoff_id` mismatch → `handoff_invalid`/`handoff_tampered`.

17. **A valid Handoff can still be not reusable.** `VALID` ≠ `REUSABLE`.

18. **A fresh Receipt can still require verification.** `FRESH` ≠ `REUSABLE` (bundler-audit DB, scope, policy).

19. **A previous PASS can still require verification.** Current policy/baseline/waiver drift or missing evidence may force `VERIFICATION_REQUIRED`.

20. **A previous FAIL can still carry reusable evidence.** `FAIL` evidence remains evidence; reuse may still be `REUSABLE` (e.g., RuboCop findings still valid).

21. **AI cannot authorize reuse.** AI advisory, off by default, never changes reuse decision or `GateResult`.

22. **PR Intelligence cannot authorize reuse.** Deterministic advisory digest, never authoritative.

23. **RepairPacket cannot authorize reuse.** Repair linkage is reference (`packet_id`), not authority; `Repair::Verifier` boundary checks remain.

24. **MCP cannot introduce a second reuse policy.** One canonical `Reuse.evaluate`; MCP delegates, no private logic.

25. **TOCTOU during reuse evaluation fails closed.** `identity_before != identity_after` (re-observed `VerificationIdentity`) ⇒ `VERIFICATION_REQUIRED`/`INCOMPLETE`, never `REUSABLE`.

**Consequences for 1.4:** Whole-set reuse only (`PER_ANALYZER_REUSE_DEFERRED`). `Reuse.evaluate(handoff, current_identity, current_contract)` is single authority for CLI/MCP/CI/Repair. Handoff bounded `256 KiB`, portable, offline, file/process/clone/CI-job usable.
