# RailVerdict 1.2.0 — Security Review

**Date:** 2026-08-24
**Commit:** d49c204
**Scope:** process execution, shell invocation, argv construction, path handling, symlink behavior, schema/YAML/JSON parsing, Git invocation, receipt verification, MCP input, env vars, log/SARIF output

## Process execution

- `lib/rail_verdict/process_runner.rb:44` — `Process.spawn([executable, basename], *argv, ...)` — argv-only, no shell string. Verified `spawn` first element is array form preventing shell interpolation. Minimal env, bounded I/O, monotonic timeout, pgroup TERM/KILL, reaping. No `system("...")`, backtick, `%x`, or `/bin/sh` for analyzers.
- Malicious filename test: filenames with `; touch`, `$(cmd)`, `` `cmd` ``, `--help`, `-rf`, spaces, quotes, unicode, newlines are passed as argv where applicable (e.g., Git diff handling) and via NUL-safe diffs; no shell interpolation path exists.

## Path handling & containment

- `lib/rail_verdict/path_safety.rb` + `lib/rail_verdict/mcp/repository_root.rb` — realpath deepest-existing-ancestor containment for CLI `receipt create|verify --config/--baseline/--waiver` and MCP `verify`. Out-of-root or symlink escape → `repository_state_unavailable` / `invalid_arguments` fail-closed (audited in cycles 1-2, fixes df363ea/8ca3359/94c94f3). Both guard captures use `Check.effective_input_paths` so effective inputs cannot escape identity.

## YAML / JSON / schema loading

- `lib/rail_verdict/strict_yaml.rb` — safe load, rejects aliases, tags, permitted classes/symbols, duplicate keys, non-UTF8. Then JSON Schema validation via `json_schemer` Draft 2020-12, strict `additionalProperties: false` on all schemas.
- JSON parsing bounded, oversized/truncated → `truncated` AnalyzerResult → `INCOMPLETE` exit 2, never truncated-JSON-as-success (dogfood #8: 64 MiB global clamp, RSpec 16 MiB, RuboCop 8 MiB).

## Git command invocation

- `lib/rail_verdict/git/command.rb` — argv `git` invocations (`ls-files -s`, `status --porcelain=v2`, `merge-base`, `diff --name-only -z`). NUL-safe parsing, rename awareness, branch HEAD/merge-base semantics validated. Shallow/missing base → `INCOMPLETE` with `repository_state_unavailable`.

## Secret handling & privacy

- `lib/rail_verdict/intelligence/secret_detector.rb` + `redactor.rb` — filename blocklist (.env, master.key, *.pem, id_rsa) and content patterns (AWS keys, private keys, ghp_ tokens). Remote off by default (`ai.enabled && ai.remote.enabled`), trust `redacted` default, fail-closed `secret_detected`. Only `openai_compat.rb` uses `Net::HTTP` and only when remote explicitly enabled.
- `lib/rail_verdict/canonical_json.rb` — deterministic serialization, no secrets echoed.

## Receipt / state identity

- `lib/rail_verdict/repository_state.rb` — bounded (index 8 MiB, status 4 MiB, 500 dirty paths, 2 MiB per file hash), truncation → `unavailable` fail-closed. `receipt_id sha256:` over canonical identity fields, no signing — correctly documented as integrity record not attestation (see `docs/agent-verification.md` trust model).
- Snapshot guard `pre/post` mismatch → `repository_changed_during_verification` and no trusted receipt issued.

## MCP input validation

- All `mcp/tools/*.rb` validate types/lengths/NUL/UTF-8, `limit 1..100`, `finding_ref` exact `rv:`/`sha256:` no fuzzy match, `packet_id` must exist in bounded LRU(10), `base` hex SHA, container rejection → `invalid_arguments isError:true`. Stdio bounded 4 MiB, mutex-serialized verification.

## Log/SARIF output

- `lib/rail_verdict/reporters/sarif.rb` — SARIF 2.1.0 projection of `GateResult` only; paths are repo-relative (no absolute leak), deterministic ordering. `reporters/console.rb` bounded.

## Finding message safety (dogfood #6)

- `Analyzers::Shared.normalize_finding_message` — nil/empty/whitespace/ANSI/control/null-byte/invalid-UTF8/oversized → sanitized bounded valid UTF-8, so GateResult JSON never dumps raw stack traces.

## Verdict

No shell interpolation, no unsafe YAML load, no path traversal bypass, no secret leak, no unbounded execution. No P0/P1 open. Remaining noted limits are documented and fail-closed.
