# 1.2.x Patch Policy

## Patch immediately

- Incorrect GateResult / false PASS / false `fresh`
- Receipt identity bug / baseline misclassification / fail-closed regression
- Security issue (see SECURITY.md)
- Broken installation / broken supported Ruby / schema contract regression

Process: reproduce → regression test → fix root cause → `rake test` → relevant Lab campaign → tag `v1.2.x` (no tag move) → release workflow (build-once OIDC).

## Consider patch

- Important CLI UX bug / doc causing incorrect configuration / significant analyzer compatibility regression

Triage vs 1.3: if workaround exists, defer to backlog (`docs/roadmap/1.3-evidence-backlog.md`).

## Usually wait for 1.3

New analyzer, integration, policy capability, UI, intelligence feature — evidence-driven backlog, not launch patches.
