## 4. Freshness vs Evidence Reuse model

- `RECEIPT_FRESH`: current `VerificationIdentity` == receipt-bound.
- `EVIDENCE_REUSABLE`: previous normalized evidence sufficient under current repo/env/analyzer/dependency/config/policy/baseline/waivers/scope/provenance/completeness.
- `VERIFICATION_REQUIRED`: otherwise, run producers.
- `ANALYZER_EVIDENCE_REUSABLE`: per-analyzer (deferred).

## 5. Evidence taxonomy

Normalized `AnalyzerResult` + `Finding` (deterministic, bounded) vs raw stdout; `Finding` message via `Shared.normalize_finding_message`.

## 6. Analyzer-specific reuse decision

- **RuboCop**: `REUSABLE UNDER` source+config+rubocop versions+Ruby, fail-closed on external `inherit_from`.
- **RSpec**: `NOT REUSABLE BECAUSE` DB/schema/ENV/nondeterminism unobservable.
- **Minitest**: `NOT REUSABLE BECAUSE` same.
- **SimpleCov**: `NOT REUSABLE BECAUSE` coupled to test execution.
- **bundler-audit**: `NOT REUSABLE BECAUSE` advisory DB can change while receipt fresh; requires DB revision.

Decision: `PER_ANALYZER_REUSE_DEFERRED`.
