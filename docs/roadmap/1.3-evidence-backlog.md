## How to add evidence

When a new report arrives:

1. Classify into taxonomy: `INSTALLATION | DOCUMENTATION | CLI_UX | COMPATIBILITY | ANALYZER | BASELINE | GIT | CI | PR_INTELLIGENCE | RECEIPT | AGENT_WORKFLOW | PERFORMANCE | BUG | FEATURE_REQUEST | SECURITY | OTHER`
2. Set severity: `LAUNCH_BLOCKER | HIGH | MEDIUM | LOW | IDEA` (correctness fail-closed bugs are HIGH).
3. Count external requests; link issues/PRs.
4. Record workaround and leave Decision `TBD` until planning.

1.3 scope is not defined in this goal — external evidence must determine it.
